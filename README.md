# Ground Cover Kit — Interactive Superhive Landing Page

A responsive, self-contained product landing page for **Ground Cover Kit** by Arsha Flora, hosted with GitHub Pages.

## Product facts

- **253 mesh models**: 78 Grass, 64 Flowering Shrubs, 20 Pampas Grass, 10 Bushes, 12 Large Bushes, 11 Dandelion Plants, 23 Dry Bushes, 19 Dry Wood, 6 Dry Leaves, 10 Stones.
- **7 soil materials**, making **260 total assets**.
- **Surface Pencil** scatter add-on, v1.4.6, for Blender 4.2+.
- Coverage modes: **Area, Path, Brush, Whole Mesh**.
- Editable scatter layers, source amounts, distribution and transformation controls.
- **Face Camera** option for camera-focused scene management.
- Eight interface languages: English, Portuguese (Brazil), German, Japanese, Spanish, French, Chinese and Russian.

## Important presentation notes

This site contains **illustrations** (CSS/SVG/emoji placeholders) and a **conceptual scatter simulator**. These are **not** rendered screenshots of actual included 3D models, nor do they run Blender logic. Replace illustrative imagery with **actual Ground Cover Kit renders and Asset Browser screenshots** before treating visual examples as product evidence. The translated UI samples are examples, not screenshots of the add-on.

The product listing CTA currently links to the creator page; update it with the actual product URL when the listing goes live.

## Deployment

This is a static site: no build tooling, backend or server is required.

1. In GitHub, open **Settings → Pages** for this repository.
2. Under **Build and deployment**, select **Deploy from a branch**, select **main**, and choose **/(root)**.
3. Save and wait for GitHub to finish deploying.
4. Open: **https://arsha-flora.github.io/op-sys-on-circuit/**.

If your GitHub account has a custom Pages domain, the URL may differ.

## Embedding on Superhive

See [SUPERHIVE_EMBED.html](SUPERHIVE_EMBED.html) for ready-to-paste HTML. Test both desktop and mobile renderings in the real Superhive editor. The site supports \`?embed=1&section=hero\`, \`library\`, \`workflows\`, \`optimization\`, \`languages\`, \`get-kit\`, and \`faq\` to embed individual sections with different heights.

**Note:** Framing depends on GitHub Pages and the browser's response security headers, and on Superhive's HTML sanitizer. Confirm that the final pages display within the product description.
